# 🤖 AI vs Human Text Detector

A machine learning-powered web application that classifies whether a given piece of text was written by **a human** or **generated by AI**. Built with Flask and scikit-learn, using a Linear SVM classifier trained on TF-IDF features.

## ✨ Features

- **Real-time text classification** — Paste any text and get an instant AI vs Human prediction
- **SVM-based detection** — Uses a Linear Support Vector Machine for high-accuracy binary classification
- **TF-IDF feature extraction** — Converts raw text into numerical features using Term Frequency-Inverse Document Frequency
- **Clean web interface** — Minimal, dark-themed UI built with Flask + Jinja2
- **Deploy-ready** — Includes a `Procfile` for one-click deployment to Heroku or similar PaaS

## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** installed on your system
- **pip** (Python package manager)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/jacobtsajan/ai-detect-final.git
   cd ai-detect-final
   ```

2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv venv

   # Windows
   venv\Scripts\activate

   # macOS / Linux
   source venv/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**
   ```bash
   python main.py
   ```

5. **Open your browser** and navigate to:
   ```
   http://localhost:5000
   ```

## 🧠 How It Works

The detection pipeline follows these stages:

```
┌──────────────┐     ┌──────────────────┐     ┌────────────┐     ┌────────────┐
│  Raw Text    │────▶│  Preprocessing   │────▶│  TF-IDF    │────▶│ Linear SVM │────▶  AI / Human
│  (user input)│     │  (clean, tokenize│     │ Vectorizer │     │ Classifier │
└──────────────┘     │   stopwords, etc)│     └────────────┘     └────────────┘
                     └──────────────────┘
```

### Training Pipeline (Notebook)

1. **Data Loading** — Load the `AI_Human.csv` dataset containing labeled text samples
2. **Exploratory Data Analysis** — Visualize class distribution with count plots
3. **Text Preprocessing** —
   - Remove HTML-like tags and special characters
   - Strip punctuation
   - Expand contractions (e.g., "can't" → "cannot")
   - Remove stopwords using spaCy's English stop word list
4. **Feature Extraction** — Apply TF-IDF vectorization with L1 normalization
5. **Model Training** — Train and compare:
   - **Logistic Regression** (L2 penalty)
   - **Linear SVM** (L1 penalty, squared hinge loss) ← *selected for deployment*
6. **Model Export** — Serialize the SVM model and TF-IDF vectorizer as `.pkl` files

### Inference (Web App)

1. User submits text through the web form
2. Flask loads the pre-trained TF-IDF vectorizer and SVM classifier from `.pkl` files
3. The input text is transformed using the TF-IDF vectorizer
4. The SVM classifier predicts the label: `1` (AI) or `0` (Human)
5. The result is displayed on the page

> **Note:** The web app uses the *pre-trained* model — it does not retrain on each request. The preprocessing done during training (stopword removal, contraction expansion, etc.) is implicitly encoded in the TF-IDF vocabulary.

## 📊 Dataset

The model was trained on the **AI_Human.csv** dataset, which contains text samples labeled as:
- `0` — Human-written
- `1` — AI-generated

> **Note:** The dataset file is **not included** in this repository due to its size. See the [Jupyter notebook](AI-VS-HUMAN.ipynb) and the [Notebook Guide](NOTEBOOK_GUIDE.md) for details on the training process.

## 🌐 Deployment

This project is configured for deployment on **Heroku** (or any platform that supports `Procfile`-based deployments):

1. Create a Heroku app:
   ```bash
   heroku create your-app-name
   ```

2. Push to Heroku:
   ```bash
   git push heroku main
   ```

The `Procfile` runs the app with Gunicorn:
```
web: gunicorn main:app
```
